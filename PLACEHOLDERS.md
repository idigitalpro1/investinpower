# Invest in Power placeholder register

This preview deliberately contains no invented mission, ownership, program, impact, partner, or contact claims. Replace each item below with approved copy before any production release.

1. **One-line purpose** — the exact mission statement used in the hero and metadata.
2. **Who it is for** — the intended audience or community.
3. **Primary action** — choose donate, sign up, contact, or learn more.
4. **Primary-action destination** — approved email address or static form endpoint.
5. **Post-click expectation** — what happens next and, if promised, the response time.
6. **Problem statement** — the factual problem the organization addresses.
7. **Supporting explanation** — who experiences the problem and its practical consequences.
8. **Sources** — direct links for every number or external factual claim.
9. **Programs or activities** — three approved activities, plus an optional fourth.
10. **Organization or owner name** — exact public identity for the about section and copyright.
11. **About copy** — verified background, location if relevant, and reason for the work.
12. **Contact email** — replace `replace-me@example.invalid` before enabling contact.
13. **Privacy note** — explain any information a future inquiry service collects and how it is used.
14. **Legal status or profile link** — include only if verified and useful.
15. **Social-share image approval** — approve the abstract placeholder card or replace it with owned media.

## Release gate

- `npm run validate:preview` allows placeholders and prints the complete detected list.
- `npm run validate:production` fails while any bracketed placeholder remains.
- Do not attach `investinpower.org`, alter DNS, enable payments, or collect visitor data from this preview.
